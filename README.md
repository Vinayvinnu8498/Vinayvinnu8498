# 🚀 Featured Cybersecurity Projects

## 🟣 Purple Team Attack Simulation & Detection Engineering Lab

**Technologies:** Splunk | Sysmon | Atomic Red Team | MITRE ATT&CK | Windows Server | Linux

- Built an isolated Windows Server and Linux security lab
- Forwarded Sysmon, PowerShell, and syslog telemetry into Splunk
- Simulated credential access, persistence, privilege escalation, and lateral movement
- Mapped attacks to the MITRE ATT&CK framework
- Created and tuned Splunk correlation searches
- Documented detection coverage gaps using an ATT&CK heat map

## 🌐 Network Traffic Forensics & Malware Communication Analysis

**Technologies:** Wireshark | tcpdump | Python | Linux | PCAP

- Analyzed packet captures with Wireshark and tcpdump
